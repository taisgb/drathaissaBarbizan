# Dra. Thássia Barbizan — prévia conceitual

Site estático (HTML, CSS, JS), com imagens locais. Coloque os arquivos na raiz do repositório e configure GitHub Pages: Settings → Pages → Deploy from a branch → main / (root). Também funciona em subdiretório da hospedagem.

Prévia não oficial, sem vínculo com a médica. A página inclui `noindex` e `robots.txt` que permite ao buscador ler a diretiva de não indexação; após aprovação, remova a diretiva de não indexação e configure domínio, SEO e dados estruturados. O `noindex` não substitui controle de acesso. Revise os serviços, textos e fotografias com a profissional antes de publicação oficial. Google Maps depende de conexão externa. As imagens são versões tratadas, não os arquivos fotográficos originais.
